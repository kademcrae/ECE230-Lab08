## Lab Questions

### In plain English describe the function and use of a multiplexer.
A multiplexer acts like a switchboard that takes multiple input signals and directs one input to a single output line based on control signals. It is used in combining data streams and choosing data sources more efficiently.
### In plain English describe the function and use of a demultiplexer.
A demultiplexer performs the exact opposite by taking a single input signal and routing it to one of multiple outputs. 
### What other uses might these circuits have? (Think Shannon’s)
Multiplexers are often used with Shannon's expansion theorem to implement complex Boolean logic functions by connecting logic variables directly into the select lines.
